# Cordova APP Builder

# Step to build new APP:
# 1. Replace APP icon in /res folder with icon file name as 'icon.png'
# 2. Fill in APP Repository secrets detail in Settings tab -> Secrets and Variables > Actions
# 3. Go to Action tab, choose Build Android APK and choose Run Workflow dropdown & click 'Run Workflow' button
# 4. After Success, download project APP in Artifacts row
